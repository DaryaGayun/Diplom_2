# Задание 2: Автотесты для API

Автотесты для проверки API сервиса Stellar Burgers.

## Реализованные сценарии

### Создание пользователя
Созданы тесты для проверки:
- создания уникального пользователя;
- создания пользователя, который уже зарегистрирован;
- создания пользователя без одного обязательного поля.

### Логин пользователя
Созданы тесты для проверки:
- входа под существующим пользователем;
- входа с неверным логином и паролем.

### Создание заказа
Созданы тесты для проверки:
- создания заказа с авторизацией;
- создания заказа без авторизации;
- создания заказа с ингредиентами;
- создания заказа без ингредиентов;
- создания заказа с неверным хешем ингредиентов.
## Технологии

- Python
- PyTest
- Allure

## Структура проекта
```
/
├─ allure-results/
├─ helpers/
├─ tests/
├─ ...
```

## Установка
```
pip install -r requirements.txt
```

## Запуск тестов
```
pytest tests/ -v
```

## Запустить тесты с генерацией Allure-отчёта
```
pytest tests/ -v --alluredir=allure_results
```

## Сгенерировать HTML-отчёт
```
allure serve allure_results
```
